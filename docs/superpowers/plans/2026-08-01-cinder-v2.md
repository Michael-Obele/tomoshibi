# Tomoshibi v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship five sprints (core quality, image engine v2, crawl v2, discovery endpoints, intelligence+hardening) that make Tomoshibi faster, crawl better, fetch images better, and add competitive features — with zero LLM dependency.

**Architecture:** Hexagonal, monolith. New code in existing feature packages plus one new package `internal/extract`. Design: `docs/plans/2026-08-01-tomoshibi-v2-design.md`.

**Tech Stack:** Go 1.25+, Gin, Colly, Chromedp, Asynq/Redis, goquery, go-readability v0.44.0, golang.org/x/sync (errgroup), golang.org/x/image (webp encode via `github.com/chai2010/webp` — see Task B4 note).

## Global Constraints

- No LLM dependency ever. All intelligence is deterministic.
- `context.Context` propagated to all blocking ops; no goroutines without lifecycle management.
- Errors wrapped with `fmt.Errorf("%w", err)`; no `_ =` error ignores; no `panic` in control flow.
- All exported symbols documented; `gofmt` + `golangci-lint` clean.
- After every task: `make check` must pass (fmt, vet, staticcheck, `go test ./... -race`).
- Table-driven tests with `t.Run` subtests.
- Logging via `pkg/logger` (`slog`), never `fmt.Println`.
- Swagger regenerated with `swag init -g cmd/api/main.go -o internal/api/docs` after handler changes (verify the actual `-g` path against main.go before first run).
- Hobby-tier: every new tunable has an env var with a conservative default.

```go
// Package-level doc in content.go
package scraper

import (
	"strings"

	"github.com/go-shiori/go-readability"
)

// ReadabilityResult holds main-content extraction output.
type ReadabilityResult struct {
	Title       string
	Excerpt     string
	Byline      string
	SiteName    string
	ContentHTML string
}

// ExtractMainContent runs readability on rawHTML. On failure it returns a
// fallback result containing the original HTML and a nil error — callers
// must never fail a scrape because extraction failed.
func ExtractMainContent(rawHTML string, pageURL string) (*ReadabilityResult, error) {
	parsed, err := readability.FromReader(strings.NewReader(rawHTML), mustParseURL(pageURL))
	if err != nil {
		return &ReadabilityResult{ContentHTML: rawHTML}, nil
	}
	return &ReadabilityResult{
		Title: parsed.Title, Excerpt: parsed.Excerpt, Byline: parsed.Byline,
		SiteName: parsed.SiteName, ContentHTML: parsed.Content,
	}, nil
}
```

(`mustParseURL` helper parses with `net/url`, falling back to a zero URL on error.)
Run `go get github.com/go-shiori/go-readability@v0.44.0`.
